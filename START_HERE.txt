DR ASHRAF CONTENT PLANNER - DAILY CHECKBOX ONLY

This version restores the original planner and keeps only the Every day checkbox update.

1) Replace the project files.
2) Delete the old media-feature files listed in UPDATE_INSTRUCTIONS.txt.
3) Run: npm install
4) Run: npm run typecheck
5) Run: npm run build:web
6) Push to GitHub main.
7) Vercel will deploy the new commit automatically.

For an existing Supabase project, no additional SQL is needed if repeat_daily already exists.
Otherwise run: supabase/20260821_daily_tasks_only.sql
