1) Copy these files over your existing D:\Projects\Dr.Ashraf-metwaly repository.
2) Run: npm install
3) Create .env from .env.example and add your Supabase URL + Publishable key.
4) Run supabase/setup.sql in Supabase SQL Editor.
5) Test: npm run web
6) Commit the updated package-lock.json created by npm install together with these files.
7) Push to GitHub. For Vercel, add the same two environment variables and redeploy.
