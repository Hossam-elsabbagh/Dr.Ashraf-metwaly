UPDATE INSTRUCTIONS

1) Back up your current repository if you want an easy rollback.
2) Copy/replace the updated source files.
3) Run the existing-project Supabase migration BEFORE deploying:
   supabase/20260821_daily_tasks_and_media.sql
4) Run:
   npm install
   npm run typecheck
   npm run build:web
5) Make sure .env is NOT committed. Use .env.example as the template.
6) Commit the source + package-lock.json, then push to GitHub.
7) In Vercel, confirm these environment variables exist:
   EXPO_PUBLIC_SUPABASE_URL
   EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY
8) Redeploy.

The media files upload directly from the browser to Supabase Storage. They do
not pass through the Vercel /api/tasks function, and the app does not compress
or resize the uploaded originals.
